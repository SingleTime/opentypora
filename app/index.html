文本片段（Text Snippet）

        

          一行一条：触发词 => 内容。内容里 \n 换行、
            \t 制表符、$0 指定光标落点；# 开头是注释。
            在编辑器里敲触发词后按 Tab 展开。
          
        


        
自定义导出命令

        

          命令交给 /bin/sh 执行，可用占位符：
            {src} 当前文档（临时 .md）、{out} 输出文件（保存面板选定）、
            {name} 文档主名、{dir} 文档所在目录、{ext} 扩展名。
            命令会原样执行，只添加你自己信任的命令。
          

        

        

          
          
        


        
自定义主题

        

          把 *.css 放进主题目录，重新扫描后会出现在上面的主题列表里。
            CSS 会叠加在内置主题之上，用 :root { --bg: …; --text: …; } 覆盖变量即可。
